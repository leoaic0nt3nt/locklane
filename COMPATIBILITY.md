# VPN compatibility / 0.1 beta

| Формат | Импорт | Ограничения |
|---|---|---|
| VLESS | URI, обычная/base64 подписка | Reality или TLS; raw/TCP, WS, gRPC, XHTTP, HTTPUpgrade. Flow `xtls-rprx-vision`. Без VLESS Encryption и XHTTP `extra`. |
| VMess | Base64 JSON URI | raw/TCP, WS, gRPC и подходящие Xray-транспорты. Проверяй результат реальным подключением. |
| Trojan | URI | TLS, raw/TCP, WS, gRPC. |
| Shadowsocks | SIP002 или legacy URI | Без внешних plugin-команд. Реальная интеграция проверяется синтетическим chacha20-ietf-poly1305 сервером. |
| Hysteria2 | `hysteria2://`, `hy2://` | TLS; salamander obfs при наличии параметров. |
| TUIC v5 | `tuic://uuid:password@…` | TLS; IPv4 upstream. |
| SOCKS5 | `socks://user:pass@…` | Сам по себе SOCKS5 не шифрует канал. Предпочитай шифрованный протокол. |
| WireGuard | `.conf`, один Peer | Полный IPv4-туннель; хуки, команды, произвольный Table и AmneziaWG-поля запрещены. IPv6 выключен; MTU фиксирован 1280, DNS профиля не используется. |
| Tailscale | Вход в свой аккаунт + IPv4 exit node | Нужен доступ к узлу и разрешение использовать его выходом. Вход этого контейнера отдельный от Tailscale хоста. |

Это матрица реализованных импортёров и движков, а не подтверждение подключения к каждому продавцу/транспорту. Сетевой integration покрывает WireGuard и Shadowsocks; остальные требуют тестового профиля и проверки на конкретном сервере.

## Happ / Incy / продавцы подписок

Happ официально перечисляет VLESS, VMess, SOCKS5, Trojan, Shadowsocks, Hysteria2 и обычные HTTPS-подписки: [документация](https://www.happ.su/main/faq/adding-configuration-subscription). Incy также предоставляет разные протоколы: [страница издателя в Google Play](https://play.google.com/store/apps/details?id=com.progoma.pero). Имя клиента не гарантирует совпадение всех функций.

Для Moriarty, Durev, Hit и других: возьми исходный ключ/обычную подписку из личного кабинета или экспорта клиента. Не передавай пароль от личного кабинета LOCKLANE. Необходим именно экспорт настройки.

- `happ://crypto…`: скрывает URL/параметры. Не дешифруется через неизвестные внешние сервисы. Запроси у провайдера обычный URL или отдельный экспорт.
- Другие закрытые app-only ссылки: нужен поддерживаемый исходный формат.
- Clash YAML, произвольный Xray/sing-box JSON и PAC не исполняются и не импортируются целиком: они могут содержать обходы, дополнительные слушатели и DIRECT-маршруты.
- OpenVPN, SSTP, OpenConnect, AmneziaWG, WireGuard с IPv6-only endpoint и плагины пока не поддерживаются.
- TLS `insecure`, skip-cert-verify и нестандартные параметры не включаются молча. При неподдерживаемом формате импорт отказывает и объясняет причину.
- Один выбранный сервер и один закреплённый внешний IP. Подписка с плавающим NAT не становится статичной благодаря LOCKLANE. После смены IP доступ закрывается; для постоянного адреса нужен соответствующий тариф или свой VPS.

Совместимость расширяется отдельным parser + конфигурационными тестами + реальным тестовым сервером. Добавлять неизвестное поле «как есть» в root-процесс шлюза нельзя.
