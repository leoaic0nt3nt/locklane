# LOCKLANE / dark glass

The user rejected the original warm-paper settings dashboard and supplied three references on 18 November 2026: a dark frosted-glass mobile interface, a black technical interface with light instruments, and a warm luminous rounded object. Those references replace the previous visual system.

## Surface

A compact controller, not a settings dashboard. The home shows only the app identity, a settings button, the power control, actual connection state, the actual exit IP and a refresh action. The Claude Code launcher appears only when the backend verifies readiness. Unknown state never looks connected. IP discovery exposes an explicit pin action while the workload remains locked.

One native modal sheet contains all setup: Connection, Workspace, Activity. The main screen has no profile inputs, project paths, logs, platform metadata or setup checklist. The sheet preserves unsaved drafts across background status polling, supports keyboard tabs, focus trapping and Escape, and can be deep-linked by its non-sensitive tab name.

## Material

Black `#08090b`, graphite `#17181c` / `#202126`, ivory `#f1f0ee`, secondary text `#a4a5ae`, warm amber `#efa16f`. Glass is purposeful on the settings sheet and IP strip. One physical power control has a dark machined face, a thin warm rim and reflected light. The warm rim is subdued while off and brighter only when verified. No fake traffic graph, percentage or location.

System UI fonts stay local. One family, 11–15 px secondary/form type, 24–27 px headings. Short state transitions; rotating rim only during real work, with a static reduced-motion alternative. Icons use the Lucide vocabulary. The L/doorway mark is the project's own.
