# LOCKLANE visual system

App screen. Warm paper, green-black ink, mint reserved for an affirmative action and verified tunnel state. Palette and 10/14 px control surfaces derive from Hallmark Dose (dealt 2/3). System fonts are local; the panel makes no external font requests before VPN setup. Reading sizes start at 12 px for secondary labels, 14–16 px for forms and 40 px for the main title. Functional controls have visible focus and 44 px targets. No animated fake traffic, country flags or invented protection score.

The live egress gate is the signature: **Выход закрыт** by default, **Статус неизвестен** if status cannot be read, **Туннель подтверждён** only after real routing and IP verification. The name and geometric L/doorway mark are original project assets. The dark panel is a working status surface, not a decorative hero. One top bar, no sidebar.

States: initial setup, missing Docker runtime, importing, subscription error/unsupported format, selected profile, build in progress, Tailscale sign-in, IP discovery with application blocked, ready, wrong IP, stale status, stopped. Errors are actionable and do not echo credentials. Workspace creation is never triggered solely by opening the panel.
