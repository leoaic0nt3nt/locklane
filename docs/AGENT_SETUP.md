# Установить через своего агента

Дай агенту распакованный пакет LOCKLANE, не чужой VPN-профиль. Настройку можно выполнить по этому заданию:

> Установи LOCKLANE из этого пакета под мою ОС и архитектуру. Не меняй текущие VPN, DNS, системный файрвол, LuLu, Claude, глобальный Docker context и автозапуск. Сначала проверь Docker Desktop и требования ОС; если нужна установка или системное разрешение, покажи официальный шаг. Открой локальную панель. Попроси меня вставить мою подписку/ключ в неё, а не в чат. Помоги выбрать один конкретный сервер и одну папку проекта, без домашней папки или секретов. Подключи шлюз, дождись определения его IP, покажи адрес и закрепи выбранный мной выход. До проверки не запускай Claude. Выполни самопроверку, затем открой защищённый терминал. Вход в Claude делаю я. Покажи, как остановить среду, где находятся локальные данные и какие проверки выполнены на моём устройстве. Не выдавай unit-тесты за проверку сети или перезагрузки.

При неподдерживаемой подписке:

> Определи формат моего подключения без вывода секрета в журнал. Если это обычный поддерживаемый URI или HTTPS/base64-подписка, импортируй через LOCKLANE. Для happ://crypto или другого закрытого формата объясни, какой стандартный экспорт запросить у провайдера. Не отправляй подписку в сторонние конвертеры. Не включай DIRECT/failover и не отключай TLS-проверку ради подключения.

Для диагностики:

> Проверь только среду LOCKLANE и её локальные журналы. Не трогай работающий VPN хоста и другие контейнеры. Если IP другой или шлюз не готов, сохрани запрет запуска. Найди минимальную причину, исправь и повтори самопроверку. Отдельно проверь реальную перезагрузку и активные соединения в согласованный момент. Не загружай публично ключи, подписки или данные входа.
