Как работает LOCKLANE

1. Установи и запусти Docker Desktop в режиме Linux containers.

2. Импортируй обычную подписку или ключ VLESS/Reality, VMess, Trojan, Shadowsocks, Hysteria2, TUIC или SOCKS5. Либо укажи WireGuard .conf или адрес Tailscale exit node. Затем укажи постоянный внешний IPv4 выбранного сервера и папку проекта.

3. Сохрани настройки и подключись. В первый раз Docker загрузит образы. Для Tailscale появится ссылка входа в твой аккаунт.

4. После проверки IP открой Claude Code. Авторизуйся внутри его терминала. Системный браузер для OAuth работает отдельно: его маршрут LOCKLANE не контролирует.

Сеть ограничивает фильтр внутри VM. Claude работает без root, без Docker socket и без домашней папки компьютера. IPv6 и доступ к локальной сети в этой версии закрыты.

LOCKLANE защищает только запущенную здесь среду, а не приложения на компьютере. Администратор хоста имеет доступ к VM. Изменение IP внутри работающего туннеля обнаруживается периодической проверкой; абсолютная защита от утечек и блокировок аккаунта не обещается.
