Как пользоваться

Выбери подключение и папку проекта, сохрани настройки и нажми включение на главном экране. Первая сборка загружает образы и может занять несколько минут. Когда появится IP, закрепи его. Затем открой Claude Code.

Защищена только работа внутри этой среды. Системный браузер для авторизации работает отдельно. Плавающий IP подписки не становится постоянным автоматически.
